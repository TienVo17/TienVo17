# 🚀 Dự án nổi bật

## 📚 Online Bookstore E-Commerce Platform

Full-stack e-commerce application được xây dựng với **Java Spring Boot** ở Backend và **React + TypeScript** ở Frontend.

### Backend Features

- Xây dựng RESTful API bằng **Java 17 và Spring Boot**.
- Sử dụng Spring Data JPA / Hibernate để thao tác dữ liệu.
- Authentication và Authorization bằng **Spring Security + JWT**.
- Role-based Authorization cho User và Admin.
- Quản lý Book, Category, User, Order, Review và Coupon.
- Tìm kiếm, filtering và pagination sản phẩm.
- Shopping Cart và Checkout.
- Order Management.
- Tích hợp thanh toán trực tuyến với **VNPay**.
- Upload và quản lý hình ảnh với **Cloudinary**.
- Database migration bằng **Flyway**.
- Implement checkout idempotency nhằm hạn chế việc tạo duplicate order.
- Container hóa ứng dụng bằng **Docker / Docker Compose**.
